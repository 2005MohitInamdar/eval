Here's the design system distilled from everything we built, so you can hand it off cleanly:

## Color Palette

**Backgrounds**
- Primary background: `white` (#FFFFFF)
- Soft accent background: `orange-50` (#FFF7ED) — used for tinted panels/headers
- Neutral secondary background: `slate-50` (#F8FAFC) — used for neutral drop zones

**Brand colors**
- **Blue** (primary/structural): `blue-500` → `blue-700` gradient (#3B82F6 → #1D4ED8) — used for the logo icon tile, "Next"/forward-progress actions
- **Orange** (call-to-action/energy): `orange-500` (#F97316), hover `orange-600` (#EA580C) — used for primary buttons (Signup, Login, Upload), borders on drop zones, accents
- **Slate** (text/neutral): `slate-900` for headings, `slate-600`/`slate-500` for body/secondary text, `slate-400` for placeholder/muted text

**Semantic/status colors**
- Red (`red-500`/`red-50`/`red-600`) — reserved strictly for destructive actions (Logout) and form validation errors. Never used for anything else, to keep it meaningful.
- Disabled states: `slate-200` background, `slate-400` text, `cursor-not-allowed`

## Design Principles / Idea

1. **Bold, heavy typography for headings** — `font-black` weight, large sizes (`text-4xl` to `text-5xl` for page titles), `tracking-tight` to keep big text from feeling loose. Headings should feel confident, not delicate.

2. **Icon tiles as brand markers** — a small rounded-square (`rounded-2xl`) gradient-blue box with a bold white letter/icon inside, paired next to the page heading. Used consistently as a "logo mark" pattern across every page.

3. **Bordered, boxed input fields (not underline-style)** — inputs get `border-2`, `rounded-xl`, generous padding (`px-4 py-3`), with a colored border (orange) rather than a minimalist bottom-line. On focus: border darkens + a soft colored glow shadow (`focus:shadow-lg focus:shadow-orange-200`).

4. **Big, bold, high-contrast CTA buttons** — primary actions (Signup, Login, Upload, Next) are large (`py-4` to `py-5`), heavy font-weight (`font-black`, `text-2xl`–`text-3xl`), solid color fill, with a soft colored shadow underneath (`shadow-lg shadow-orange-500/25`) for a slight "lifted" feel. Secondary/alternate actions use a lighter tint version of the same color (e.g. `bg-orange-100 text-orange-700`) rather than a totally different palette.

5. **Dashed borders = drop zones** — any drag-and-drop area uses `border-dashed` specifically, since that's the universal visual convention users recognize instantly. Paired with an icon, primary label, helper subtext, and an embedded action button, all readable — never rely on color alone to signal interactivity.

6. **Generous whitespace, percentage-based containers** — main content areas sized as a percentage of viewport (`w-[70-80%]`) rather than fixed pixel max-widths, so layouts breathe and scale across screen sizes instead of feeling small/centered-in-a-box on large monitors.

7. **Staggered fade-in-on-load animation** — every page element fades in with a slight upward slide (`opacity 0→1`, `translateY(16px→0)`), staggered in reading order (header first, then content, then CTAs) via incremental `animation-delay` (typically 100–200ms increments). Defined globally (not per-component) so it's reusable everywhere:

```css
@keyframes fadeSlideUp {
    from { opacity: 0; transform: translateY(16px); }
    to { opacity: 1; transform: translateY(0); }
}
.fade-in {
    opacity: 0;
    animation: fadeSlideUp 0.6s ease-out forwards;
}
```

8. **Disabled states are visually muted, not just non-functional** — grey background, grey text, `cursor-not-allowed`, clearly distinct from the active/enabled colorful state, so users immediately understand why a button isn't responding.

9. **Overall mood**: clean, modern SaaS — approachable rather than corporate-stiff, bold rather than minimal-to-the-point-of-boring. Think "confident startup product," not "enterprise dashboard" or "cyberpunk terminal" (which is what the original theme was, before you pivoted away from it).

That should be enough for another AI or designer to replicate the system consistently without needing to see every individual component we built.
